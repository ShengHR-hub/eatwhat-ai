## 1. 市面成熟效果调研结论（均已核实）

### 1.1 商业产品范式（借设计，不借代码）

- **阿里 DataV**：组件体系含数字翻牌器（前缀/千分位/只涨不跌的抖动修正）、地图飞线层、轮播列表（自动滚动+逐行高亮）；模板按「指挥中心/地理分析/实时监控/汇报展示」分场景。文档：https://www.alibabacloud.com/help/zh/datav/datav-6-0/user-guide/digital-flip
- **百度 Sugar BI**：官方组件清单直接含**日历热力图、坐标热力图**、平面地图（气泡/热力/飞线）、点聚合/蜂窝聚合层、数字翻牌器、轮播表格；图表联动全版本标配、下钻基础版起。文档：https://cloud.baidu.com/doc/SUGAR/index.html
- **腾讯云图 TCV**：组件六大类与 DataV 高度趋同（翻牌器、轮播表格、水位图、3D 地图），说明这套组件语言已是行业默认。
- **帆软 FineVis/FineBI**：轮播 KPI 指标卡、水球图（完成度）、场景地图；业务看板范式 = 顶部全局筛选器一处筛选全图联动、点图下钻明细；画布按 1920×1080 定基准。
- **AntV L7**（开源实现层）：WebGL 地理可视化，**明确支持高德底图**；热力分经典/蜂窝/网格三种，点图层有气泡/聚合。https://github.com/antvis/l7
- **Power BI / Tableau Public 范式**：顶行指标卡、每张图标题写成它要回答的问题、一屏讲一个故事、配色克制留白足。

**布局规律（五家共识）**：① 第一视线是标题 + 几个大数字，不是图表；② 有地理数据时地图占 C 位、两侧挂趋势与榜单；③ 明细靠自动轮播，不靠滚动条；④ 一屏一主题、图表分工明确（趋势=折线、分布=地图、结构=环形、对比=柱状）；⑤ 联动/下钻是标配，静态截图式大屏已被淘汰。

### 1.2 开源可直接用的（借组件/骨架）

- **GoView**（dromara/go-view，MIT）：**Vue 3 + TS + Vite + ECharts 5 + Pinia**，与本项目技术栈几乎同构；其组件清单本身就是大屏物料表：边框 01–13、装饰、数字翻牌、滚动排名列表、滚动表格、词云、热力图、中国地图、水球图、雷达图。https://github.com/dromara/go-view
- **DataV**（DataV-Team/DataV，MIT，约 9.7k stars）：Vue 大屏组件库，13 种科技感边框、飞线图、轮播表；注意主仓为 Vue 2 用法，Vue 3 需看其 React/社区移植，借鉴视觉语言为主。https://github.com/DataV-Team/DataV
- **iDataV**（yyhsong/iDataV，约 5.7k stars，许可证未标注）：原生 JS + ECharts 的成品大屏案例合集，地图热点/飞线/百度热力/词云/水球/关系图的完整 option 写法可拆解参考。https://github.com/yyhsong/iDataV
- **DataEase**（约 24.6k stars，GPLv3 系协议）：只借鉴其模板市场的信息架构，不引入代码。
- 注意：AJ-Report 旧版本有公开 CVE（SQL 注入等），且本次核查其仓库状态异常，**不采用**，仅记录。

### 1.3 ECharts 官方示例（实现时逐个对照 option 写法）

示例库入口 https://echarts.apache.org/examples/zh/index.html ，本方案用到的示例 ID：`calendar-heatmap`（日历热力）、`heatmap-large`（矩阵热力）、`heatmap-map` / `geo-map-scatter`（地图热力与散点）、`radar-multiple`（多雷达对比）、`area-stack-gradient`（堆叠面积趋势）、`bar-y-category`（横向排行榜）、`bar-race-country`（动态排序竞赛）、`sankey-itemstyle`（桑基流向）、`graph-force`（关系图谱）；词云用官方生态扩展 `echarts-wordcloud`（ecomfe 维护，对应 ECharts 5）。

**一条实现红线**：官方 `heatmap-bmap` / `effectScatter-bmap` 依赖百度地图 AK，与本项目已锁定的高德数据源冲突，**禁用**。地图层实现二选一：① 高德 JS API（自带热力图插件 + 点聚合）绘底图与热力，ECharts 管其余图表；② ECharts geo + 自定义 GeoJSON（校园/城区轮廓）绘散点与分级着色。默认走 ①（与 POI 的 GCJ-02 坐标天然一致）。

### 功能扩容（不只是图）

- **全局筛选联动**：顶部筛选器（校区 `campus`、模式 外食/下厨、菜系）一处切换，全屏图表联动刷新；校区切换后推荐/POI/统计同步刷新，跨校区不混算。
- **下钻**：点地图门店气泡/榜单行 → 跳 DataManage 对应明细（大屏与管理页打通），下钻保留 campus 过滤。
- **DataManage 数据质量面板**：打标覆盖率、缺失字段 Top、向量分布异常数——把「数据是真的」做成可见证据（可与 #17 合并）。

## 3. 大屏版式（1920×1080，深色版单色令牌）

```text
┌ 标题栏：食刻 · 数据与实验大屏          [校区/模式/菜系筛选] ┐
├ 翻牌数字带：校区+合计（思源 805=605真实+200合成；建大 6,859=6,659真实+200合成）│ 菜品/特征值/流水/投票按实际库 ┤
├ 左列            ┌ 中列（C 位）          ┐ 右列              ┤
│ 菜系构成环形图   │ POI 地图（散点+热力）   │ 实验一 双曲线       │
│ 时段矩阵热力图   │                        │ 实验二 分组柱状     │
│ 人设雷达对比     ├────────────────────┤ 热门菜品轮播榜     │
│                 │ 60 天日历热力图（横贯） │                   │
└─────────────────┴──────────────────────┴───────────────────┘
```

- 配色与全系统一致：大屏用深色版令牌（近黑底 `#17171A`、银灰线、白字），图表色板用灰阶 + 银色渐变，热力图用单色深浅（灰→银白），不引入彩虹色板——与移动端黑灰银白口径统一，这也是与市面蓝绿科技大屏的差异化。
- 每张图标题写成问题式（借 Power BI 范式）：如实验一标题「防腻衰减真的降低了重样率吗？」，先给结论再给证据。
