v2.3.6 · G4 仅限管理员访问

登录管理后台

使用管理员账号登录。普通账号会被拒绝。

用户名或密码错误

没有管理员账号？让已有管理员执行 python -m backend.scripts.grant_admin --username 你的账号 授权。注册接口不允许自选角色。

没有管理权限

你已经登录成功，但当前账号的角色不是管理员，无法进入后台。
